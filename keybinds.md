# Keyboard Shortcuts & Controls

This guide covers the default keyboard controls in GeoFS. Note that some keys may behave slightly differently depending on your keyboard layout (e.g., QWERTY vs. AZERTY) or active browser add-ons.

---

# Primary Flight Controls

| Key | Action |
| :--- | :--- |
| `Up Arrow` / `Down Arrow` | Pitch down / Pitch up (Elevator) |
| `Left Arrow` / `Right Arrow` | Roll left / Roll right (Ailerons) |
| `,` (Comma) / `.` (Period) | Yaw left / Yaw right (Rudder) |
| `K` | Toggle keyboard flight control mode |
| `M` | Toggle mouse flight control mode |

---

# Engine & Throttle

| Key | Action |
| :--- | :--- |
| `E` | Start / Stop engine(s) |
| `+` / `-` (or `=` / `-`) | Increase / Decrease throttle |
| `Page Up` / `Page Down` | Increase / Decrease throttle (alternative) |
| `0` through `9` | Set throttle directly (0% to 90%) |
| `Spacebar` | Wheel brakes (hold) / Toggle parking brake on ground |
| `B` | Toggle airbrakes / spoilers |
| `R` | Toggle thrust reversers (on supported jet aircraft) |

---

# Flaps, Gear & Systems

| Key | Action |
| :--- | :--- |
| `G` | Raise / Lower landing gear |
| `[` | Retract flaps one notch |
| `]` | Extend flaps one notch |
| `F` | Cycle flaps down |
| `A` | Toggle Autopilot on / off |
| `X` | Toggle additional aircraft animation / special feature (e.g., cargo door, canopy, hook) |

---

# Camera & Views

| Key | Action |
| :--- | :--- |
| `C` | Cycle camera views (Cockpit, Follow, Free, Wing, etc.) |
| `1` – `6` *(when in camera menu)* | Switch directly to specific camera presets |
| `Numpad` / `Mouse Drag` | Look around in cockpit or external view |
| `Mouse Wheel` | Zoom in / Zoom out |

---

# Interface & Navigation

| Key | Action |
| :--- | :--- |
| `P` | Pause / Unpause simulation |
| `H` | Hide / Show HUD and bottom interface bar |
| `V` | Toggle multiplayer chat window |
| `S` | Toggle sound on / off |
| `T` | Reset aircraft position to nearest runway / air start |
