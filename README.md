# About This Repository

This repository is a structured reference manual and field guide for GeoFS. It brings together keyboard shortcuts, autopilot and ILS landing procedures, aircraft speed cheat sheets, and browser performance tips in one easy-to-read place.

### **Table of Contents**

* **[Keyboard Shortcuts & Controls](keybinds.md)** — Complete list of flight controls, camera views, flaps, gear, and autopilot keys.
* **[Autopilot & ILS Landing Guide](autopilot-ils-guide.md)** — Step-by-step instructions on setting altitude, heading, speed, and executing automated ILS approaches.
* **[Aircraft Speed Cheat Sheet](aircraft-speeds.md)** — Reference table with takeoff ($V_R$), cruise, and landing approach speeds (in knots) for default aircraft.
* **[Browser Performance & FPS Tips](performance-tips.md)** — Settings and tweaks to reduce lag and keep GeoFS running smoothly.

# How to Use This Manual

Click on any of the sections above to open that specific guide. *If you notice outdated aircraft speeds, missing shortcuts, or have a tip you'd like to add, feel free to open an issue in this repository.*
